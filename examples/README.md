# Example presets: bench tests on a Blustream DA44AU

| File | What it is |
|---|---|
| 01-generic-before-fix.xml | Generated by an early version of the editor: a generic device with **no `<friendly_name>`**. Applied to the DA44AU. |
| 02-exported-after-applying-01.xml | Exported from Dante Controller after applying 01. Channel names applied, **device name did not**. This is also the full real DA44AU export the device template came from. |
| 03-generic-with-friendly-name.xml | Generated after the fix: the same device **with `<friendly_name>`**. |
| 04-exported-after-applying-03.xml | Exported after applying 03. **The device name applied (BlueStream)**, but the channel names did not on that run (see docs/05 §4). |
| 05-exported-static-ip.xml | Exported after setting the DA44AU to a **static IP** in Dante Controller. This is the source of the static-IP XML format. |

The tests in `tests/run-tests.js` use these files.
